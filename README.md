## Instrucciones para correr el proyecto

1. Abrir el proyecto en la terminal.
2. Ejecutar el comendo `npm install` para instalar las dependencias necesarias.
3. Ejecutar el comando `npm start` para iniciar la api local.
4. Abrir el archivo `index.html` en un navegador web para interactuar con la aplicación.
